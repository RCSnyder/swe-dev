# Decision-Directed Evidence Planning

Use this reference when the current decision is `REQUIRE_EVIDENCE`, `CONSTRAIN`, or `SHADOW` and the user needs the cheapest credible way to move forward.

## 1. Start From The Decision, Not From Available Tools

Do not ask “what tests can we run?” first.

Ask:

> Which unresolved proposition is actually preventing the desired action?

Example:

```text
Desired action: 100-percent rollout
Blocking claim: rollback reader can decode all records written by schema v2
```

## 2. Name Competing States

Evidence is valuable when it discriminates alternatives.

```text
H_good: every v2 record remains readable by v1
H_bad: at least one v2 encoding cannot be read by v1
```

A check that passes under both hypotheses has little decision value.

## 3. Enumerate Evidence-Producing Actions

Examples:

- targeted regression test;
- property/fuzz test;
- mutation/known-bad contrast;
- model checker;
- proof;
- static analysis;
- provenance verification;
- production query;
- canary;
- shadow execution;
- synthetic monitor;
- independent implementation/verifier;
- domain-owner review;
- explicit transition witness.

For each candidate estimate:

```text
cost
latency
semantic reach
independence from existing evidence
risk / side effect
whether it can actually change the decision
```

## 4. Prefer The Smallest Credible Set

Conceptually choose evidence set `E*` minimizing cost subject to satisfying the decision obligations:

```text
minimize Cost(E)
subject to ActionAdmissible(current_state + E)
```

Do not pretend to solve an optimization problem numerically unless costs and constraints are real. The practical version is ranked alternatives with reasons.

## 5. Use Progressive Authority

Sometimes the cheapest evidence is generated by a smaller action.

Instead of:

```text
BLOCK full rollout until certainty
```

prefer when justified:

```text
5-percent canary
+ mandatory telemetry
+ automatic rollback threshold
+ short expiry
```

The canary is both a constrained action and an evidence-producing experiment.

Do not use a canary when the harm is irreversible even at small scale.

## 6. Preserve Independence

New evidence that shares the same blind spot may add little.

Examples:

- another test generated from the same faulty specification;
- two LLM reviewers using the same source summary;
- a second verifier using the same invalid environmental assumption.

Prefer evidence that attacks the uncertainty from a different causal or epistemic route when consequence warrants the cost.
